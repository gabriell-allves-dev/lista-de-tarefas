# Lista de tarefas em Python

---

Projeto desenvolvido para praticar conceitos básicos de Python.

---

## Funcionalidades

- Menu interativo
- Adicionar tarefas
- Listar tarefas
- Remover tarefas

--- 

## Tecnologias

- Python 3

---

## Como executar

### Windows

1. Baixe ou copie o projeto para o seu computador.

2. Abra a pasta lista-de-tarefas.

3. Dê dois cliques no arquivo executar.bat.

4. O programa será iniciado automaticamente no terminal.
